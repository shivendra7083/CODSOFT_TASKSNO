# CODSOFT Java Development Internship Tasks

This repository contains all five Java Development internship tasks listed in the CodSoft internship document.

## Tasks
1. Number Game
2. Student Grade Calculator
3. ATM Interface
4. Quiz Application with Timer
5. Student Course Registration System

The internship document requires at least 3 tasks for successful completion. All 5 tasks are included here for completeness.

## Requirements
- Java 17 or newer recommended
- No external dependencies

## How to run
Each task is a standalone Java console application. Open the task folder and compile/run the `.java` file.

Example:
```bash
javac NumberGame.java
java NumberGame
```

